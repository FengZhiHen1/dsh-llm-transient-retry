## 事实来源分级（本仓库要求）

本插件文档里的每条断言都标注来源等级，三者不可混写：

- `[读码]` —— 直接读 DSH 源码检出（基线见 `技术设计.md` §1）或本机装机件得到。
- `[实测]` —— 在本机实例上跑出来的观察。
- `[推断]` —— 由前两者推出但未直接验证；**必须写明如何验证**。

上游现象数据来自 `E:\Project\DSH_Plugins\references\Codex断连.md`（扫描于另一台 Linux 主机的 `$DSH_HOME`，其 `data/*.json` 明细**不在本仓库**）——引用该报告的计数时一律注明「转引，未在本机复核」。
